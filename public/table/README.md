# KuKu'Ku Table Game

Веб-игра для стола в кофейне: планшет ведущего + телефоны гостей.
PHP 8.1+, MySQL 5.7+ / MariaDB 10.4+, чистый JS без сборки и фреймворков.

## Как идёт игра

1. Ведущий открывает `host.php` на планшете, вводит пароль и нажимает «Открыть новый стол». На экране появляются QR и 4-значный код.
2. Гости сканируют QR (или открывают сайт), вводят код и выбирают язык: EN / RU / ΕΛ. Без кода войти нельзя, без пароля нельзя открыть стол или начать игру.
3. Каждый гость выбирает карточку. Карточка — это название трека, оно же имя гостя в игре. Одну карточку может взять только один человек.
4. Ведущий нажимает «Start the game». Можно играть все 10 треков или только занятые карточки (галочка).
5. Для каждого трека:
   - **Слушаем.** Трек играет с планшета (колонка по Bluetooth), с секунды, заданной в админке. Длина фрагмента — `listen_seconds`. Владелец карточки получает на телефон «Это твоя карточка! Ты начинаешь разговор».
   - **Комментарии.** Каждый пишет на телефоне, что почувствовал (до 200 символов), или жмёт «Пропустить». Таймер — `answer_seconds`.
   - **Итог AI.** Когда ответили все или вышло время, AI (Claude) пишет итог стола в 2 предложения и вопрос для обсуждения. Итог приходит сразу на трёх языках: каждый гость видит свой, планшет — язык ведущего. Подпись: «✨ Written by AI from your answers».
   - **«Следующий трек».**
6. После 10-го трека: «The game is over». На планшете — QR на музыку и на сайт. На телефонах — форма: имя, телефон, email, Instagram и согласие. Контакты попадают в админку (вкладка «Контакты», выгрузка в CSV).

## Установка (примерно 20 минут)

1. Залить все файлы на хостинг, например в `https://kukuku.club/table/`. Нужен HTTPS: на HTTP камера телефона и звук работают хуже.
2. Создать базу MySQL и импортировать схему:
   ```
   mysql -u USER -p DBNAME < install/schema.sql
   ```
3. Скопировать `config.sample.php` в `config.php` и заполнить:
   - доступ к базе;
   - `admin_password` — пароль ведущего;
   - `ai_api_key` — ключ Anthropic (https://console.anthropic.com). Без ключа игра работает, но вместо AI-итога показывает 3 анонимные цитаты гостей.
4. Дать PHP права на запись в `uploads/audio` и `uploads/covers`.
5. В `php.ini` (или в панели хостинга) поднять лимиты загрузки mp3:
   ```
   upload_max_filesize = 32M
   post_max_size = 40M
   ```
6. Открыть `admin.php` и загрузить 10 треков: название, mp3, квадратная обложка, секунда старта (например, с припева) и порядок.
7. В «Настройках» нажать «Проверить AI».

Если сервер — **nginx**, а не Apache, файлы `.htaccess` не работают. Нужно закрыть доступ к `config.php`, `/inc/`, `/install/` и запретить выполнение PHP в `/uploads/`:
```
location ~ ^/(config\.php|config\.sample\.php|README\.md|inc/|install/) { deny all; }
location ^~ /uploads/ { location ~ \.php$ { deny all; } }
```

## Файлы

| Файл | Что это |
|---|---|
| `index.php` | экран гостя (телефон) |
| `host.php` | экран ведущего (планшет) |
| `admin.php` | админка: треки, столы, контакты, настройки |
| `api.php` | все запросы игры (JSON) |
| `inc/game.php` | логика игры и состояния |
| `inc/ai.php` | запрос к Claude API и разбор ответа |
| `assets/js/i18n.js` | все тексты интерфейса на EN / RU / EL — править здесь |
| `assets/css/app.css` | стили в духе kukuku.club (цвета и радиусы — в `:root`) |
| `assets/fonts/` | шрифты Inter и Gugi, лежат локально, без Google Fonts |
| `install/schema.sql` | таблицы базы |

## Как устроено

- Синхронизация — опрос сервера: планшет раз в 1 с, телефоны раз в 1,5 с. На 10 человек нагрузка мизерная, WebSocket не нужен.
- Гость определяется по httpOnly-cookie. Если перезагрузить страницу, гость вернётся в игру с той же карточкой.
- От перебора кода: 15 неверных попыток с одного IP — пауза 10 минут. Код живёт `code_ttl_hours` часов и перестаёт работать, когда игра закончена.
- Приватность:
  - в AI уходят только тексты комментариев и название трека — без имён и контактов;
  - после игры комментарии удаляются (`delete_answers_after_game`);
  - контакты сохраняются только при отмеченном согласии.
- Если AI не ответил за `ai_timeout` секунд или ответил с ошибкой, показываются цитаты гостей и игра идёт дальше.
- Звук играет только с планшета. Если браузер заблокирует автозапуск, появится кнопка «Нажмите, чтобы включить звук». Лучше всего работает Chrome на Android-планшете или Safari на iPad, экран не должен гаснуть.

## Что поменять под себя

- Тексты — `assets/js/i18n.js`.
- Число треков, время фрагмента и время на ответ — `config.php`.
- Модель AI — `ai_model` (по умолчанию быстрая и дешёвая `claude-haiku-4-5-20251001`).
- Тон AI-итога — промпт в `inc/ai.php`.
